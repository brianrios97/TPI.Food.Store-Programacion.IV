Trabajo Práctico Integrador para la materia **Programación IV** (Tecnicatura Universitaria en Programación a Distancia - UTN).

Desarrollado por: **Brian Emanuel Rios**

- **Repositorio de GitHub:** [https://github.com/brianrios97/TPI.Food.Store-Programacion.IV](https://github.com/brianrios97/TPI.Food.Store-Programacion.IV)

---

## 🏗️ Arquitectura General

- **Backend:** Python 3.12 + FastAPI + SQLModel + PostgreSQL / SQLite con arquitectura en capas y patrón Unit of Work. Autenticación JWT en cookie HttpOnly.
- **Frontend:** React 19 + TypeScript + Vite 7 + Tailwind CSS 4. Gestión de estado con TanStack Query y Zustand. Tablas y formularios con TanStack Table y TanStack Form.
